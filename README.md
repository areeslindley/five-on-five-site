# Five on Five

An unofficial, non-commercial hockey statistics site: results, expected goals, standings,
and two home-grown win-probability models (Elo and Dixon-Coles).

This folder is generated by a private repository and published as-is. It contains static
files only; edit nothing here by hand, because the next build replaces it.

* Data through: 2026-10-09 (built 2026-10-11T01:20Z UTC)
* Results, expected goals and goalie data: [MoneyPuck](https://moneypuck.com/data.htm), used with
  credit for non-commercial purposes.
* Upcoming games, when listed, come from a fixture feed named beside the list (teams and start
  times only; no odds are requested or shown).
* No closing-line prices or posted totals are published here. The closing line (from the
  Sportsbook Reviews Online NHL archive, kept off this site) is used only as a benchmark, and
  only its aggregate scores appear.
* Not affiliated with or endorsed by the NHL or any club. Team names are used to identify teams.
